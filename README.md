## 미디어 교체

`media.js`의 해당 항목을 수정합니다. 정지 이미지에는 `type: "image"`와 `src`를,
실제 영상에는 `type: "video"`, `src`, 필요하면 `poster`를 지정합니다.
영상으로 교체하면 `statusLabel`도 `실제 발행 영상`으로 고칩니다.
현재 릴스 화면은 실제 발행물의 정지 캡처이며 영상 재생을 가장하지 않습니다.
캐러셀은 `type: "carousel"`과 `images` 배열을 사용합니다.
원본 매체 로고·광고 표기를 보존하고 발행 상태가 확인된 콘텐츠만 `actual`로 표시합니다.
