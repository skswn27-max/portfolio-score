# 이난주 메디큐브 지원 포트폴리오

2026-10-28 JD와 프로젝트별 발행 결과를 반영한 정적 웹 포트폴리오입니다.
기존 GitHub Pages 주소를 유지합니다.

## 구성

- 상단: 매체 협업, 인물 협업, 오프라인 경험, 파트너 협업 운영, 프로젝트 관리, MR 분석 사례로 이동
- 11개 프로젝트: 직접 역할 → 주요 성과/산출물 → 기획과 실행 → 현장/발행물 → 추가 콘텐츠
- 기존 휴대폰 목업 11개, 나눔스퀘어 네오 4종, 베이스캠프 중앙 매체 콜라주 유지
- 발행 링크는 제공 집행표의 고유 게시물 기준. 프로젝트 전체 결과와 개인 담당 범위 구분

## 이미지·영상 추가

각 프로젝트에 3개씩, 총 33개의 추가 콘텐츠 자리가 있습니다.

1. 실제 이미지나 영상을 `assets/` 폴더에 넣습니다.
2. `content-slots.js`에서 해당 프로젝트와 슬롯 ID를 찾습니다.
3. `src`에 파일 경로를 입력합니다. 예: `assets/runfit-interview.mp4`
4. 영상은 `type`을 `video`로 바꾸고 필요하면 `poster`를 추가합니다. 이미지는 `image`로 둡니다.
5. `alt`에 이미지 또는 영상 내용을 설명합니다. 화면의 제목·설명은 해당 슬롯의 `index.html` figcaption에서 수정합니다.

비어 있는 src는 ‘콘텐츠 추가 예정’으로 표시됩니다. 업로드·저장 기능은 없으며 파일과 설정을 편집하는 방식입니다. 영상은 자동 재생하지 않고 사용자가 재생합니다. 이미지는 선택하면 확대됩니다.

기존 휴대폰 화면은 `media.js`에서 관리합니다. 원본 UI가 들어 있는 캡처에는 앱 UI를 중복 합성하지 않습니다. 정지 캡처는 영상으로 표시하지 않습니다.

## 파일

- `index.html`: 원고, 프로젝트별 결과와 릴리즈 링크, 콘텐츠 슬롯
- `styles.css`: 기존 디자인, 폰트, 휴대폰, 확대 보기
- `jd-layout.css`: JD 상단과 공통 프로젝트 구성, 반응형 규칙
- `app.js`: 이미지 확대, 미디어 표시, 진행 표시
- `media.js`: 기존 휴대폰 화면 설정
- `content-slots.js`: 프로젝트별 추가 콘텐츠 설정

원본 자료, 내부 예산·매출·연락처와 감사 기록은 이 공개 폴더에 넣지 않습니다.
