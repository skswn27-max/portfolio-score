# 이난주 · 여기어때 Contents Marketer 포트폴리오

주소: https://skswn27-max.github.io/portfolio-score/yeogi-contents/

대표 사례의 순서: 1) 닝닝 캠페인 뉴미디어 발행 콘텐츠, 2) 26FW 완성 커뮤니케이션 문서의 구성·메시지·카피 편집, 3) 26SS 봄·여름 인플루언서 비주얼 브리프.

협업 콘텐츠 기획, 파트너 협의·검수, 성과 분석을 중심으로 담당 범위를 표현합니다. 직접 촬영·영상 편집 또는 공식 Owned 채널 운영 실적으로 표현하지 않습니다.

신규 이미지 8개는 사용자가 제공한 작업 자료에서 추출했습니다. 26FW 6개 비주얼은 원본 문서 카피와 함께 발췌·재구성했으며 원본 화면 캡처가 아닙니다. 26SS 가이드 2개는 참고 이미지와 AI 예시를 포함하는 기획 자료이며 최종 발행 콘텐츠가 아닙니다. 원본 회사 자료 전체, 후보 연락처, 예산·계약·물량·미공개 일정은 포함하지 않습니다. 내부 대시보드는 비식별 이미지를 유지합니다.

웨이브 제인 기획안과 분석·타 브랜드 경험은 보조 사례입니다. 목표 지표를 달성 실적으로 사용하지 않으며, 캠페인 전체 성과와 개별 콘텐츠 기여를 구분합니다.

정적 HTML/CSS/JavaScript 사이트입니다. 기존 루트 포트폴리오는 수정하지 않고 yeogi-contents 하위만 업데이트합니다.
