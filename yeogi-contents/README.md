# 이난주 여기어때 콘텐츠 마케터 포트폴리오

주소 https://skswn27-max.github.io/portfolio-score/yeogi-contents/

뉴미디어·인플루언서 협업 콘텐츠 기획 중심의 지원 포트폴리오입니다. 담당 범위를 기획, 파트너 협의, 검수, 성과 분석으로 표현하고 직접 촬영·편집이나 공식 Owned 채널 운영 실적으로 포장하지 않습니다.

대표 사례는 발행된 뉴미디어 캠페인 콘텐츠, 파트너 선정과 콘텐츠 포맷 기획, 브랜드 메시지의 콘텐츠 확장·편집입니다. 기획 자료와 발행 콘텐츠는 상태를 표시해 구분합니다. 조회수·발행 건수의 목표를 달성 실적으로 사용하지 않습니다.

회사 원자료, 원페이지 캡처, 후보 개인 연락처, 예산·단가·물량·계약·미공개 일정은 공개하지 않습니다. 공개 페이지의 이미지는 이전 포트폴리오의 검증된 이미지이며 새 기획 내용은 기준과 프로세스를 요약해 재구성했습니다. 내부 대시보드는 기존 비식별 이미지를 유지합니다.

기존 저장소의 루트 포트폴리오에는 변경하지 않으며 yeogi-contents 하위만 업데이트합니다. 정적 HTML CSS JavaScript 사이트이며 별도 빌드가 없습니다.
