# 이난주 여기어때 콘텐츠 마케터 포트폴리오

여기어때 Contents Marketer 지원용 별도 페이지입니다.

주소 https://skswn27-max.github.io/portfolio-score/yeogi-contents/

대표 프로젝트 3개와 추가 프로젝트 4개, 채널별 콘텐츠 기획과 운영 과정, 경력 및 학력을 소개합니다. 기존 저장소의 루트 포트폴리오는 변경하지 않습니다.

원본 이력서와 최신 포트폴리오의 사실 관계를 적용했습니다. 듀베티카 성과는 2025년 상반기 BEP 개선으로 정정했으며, 불확실한 매출 증가율과 조회 수는 제외했습니다. 내부 대시보드 이미지는 비식별 처리된 기존 파일을 사용합니다.

별도 빌드가 없는 정적 HTML CSS JavaScript 사이트입니다.

공개 페이지에는 개인 연락처, 프로필 사진, 이력서의 상세 인적 정보를 포함하지 않습니다. 프로젝트 내용과 이미지의 원본은 해당 계정의 기존 공개 포트폴리오입니다.
