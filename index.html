제안 01 / 일반인 오리지널 콘텐츠

〈내일, 더 가까이〉가칭

관계가 궁금해서 보고, 메디큐브의 준비 루틴을 기억하는 72시간 연애 관찰 콘텐츠.

왜 메디큐브인가

피부 고민을 연구하는 스킨케어와 뷰티테크를 ‘중요한 만남을 앞둔 나의 준비’에 연결합니다. 출연자의 피부 고민 → 제품 선택 → 사용 장면이 매회 반복되는 ‘준비의 방 by medicube’을 고유 코너로 만듭니다.

EP.01 / 첫 만남 전

“가까이 마주 볼 준비됐어?”

첫인상 인터뷰와 데이트 준비를 교차 편집. 세안 후 패드를 사용하는 손동작과 피부결 클로즈업으로 루틴을 보여줍니다.

제로모공패드 2.0전달 기능: 모공·피부결 케어제형·사용 면·사용 순서를 짧은 기능 카드로 설명
EP.02 / 함께한 하루 뒤

“오늘의 진심을 지우기 전”

저녁 스킨케어와 속마음 인터뷰를 연결. 앰플을 바르는 장면에서 제형·도포량과 토닝 케어의 쓰임을 담습니다.

PDRN 핑크 펩타이드 앰플전달 기능: 흔적·잡티 토닝 케어성분과 기능은 공식 제품 정보 기준으로 짧게 표시
EP.03 / 마지막 선택 전

“내일, 한 걸음 더 가까이”

출연자가 스스로를 준비하는 시간과 마지막 선택을 교차 편집. 디바이스 모드·움직임·사용 순서를 클로즈업합니다.

AGE-R 부스터 프로 X2전달 기능: 흡수 부스팅·탄력·광채 케어공식 사용법에 맞춘 루틴을 별도 쇼츠로도 제작

브랜드가 떠오르는 장치

매회 같은 ‘준비의 방’·거울 프레임·제품별 루틴 카드로 기억을 쌓습니다. 엔딩 질문은 “당신의 내일을 준비하는 루틴은?”

몰입에서 탐색으로

본편은 관계 서사 중심. 기능 설명은 짧은 카드와 루틴 쇼츠로 보완하고, 고정 댓글·더보기의 회차별 루틴 링크로 제품 탐색을 연결합니다.

성공을 확인하는 기준

본편 시청 유지율·다음 편 이동, 비보조 브랜드 회상·기능 이해도, UTM 제품 방문·장바구니를 분리 측정합니다. 브랜드 조사는 비노출군과 비교합니다.

제안 02 / 셀럽 활용 팬덤 콘텐츠

〈최애의 에스테틱샵〉가칭

최애가 직접 준비한 메디큐브 루틴과 팬의 질문이 만나는, 보고 싶은 셀럽 케어 토크쇼.

유튜브 자체 제작셀럽 호스트 + 게스트회차별 12–15분 제안팬덤의 재시청·공유 유도
왜 메디큐브인가

스킨케어와 AGE-R로 구성한 ‘메디큐브 루틴 바’를 고정 세트로 사용합니다. 셀럽이 게스트의 피부 고민을 듣고 루틴을 소개하는 과정에서 제형·사용 순서·디바이스 모드를 보여줍니다.

장면 01 / 팬이 고른 질문

“최애의 관리 비밀, 대신 물어봐요”

팬 커뮤니티의 사전 질문과 게스트의 일상 고민으로 대화를 시작합니다. 무대·촬영 전 준비 습관과 의외의 취향을 공개해 팬의 시청 이유를 만듭니다.

제로모공패드 2.0모공·피부결 케어 루틴사용 면과 순서를 셀럽의 손동작으로 보여주기
장면 02 / 최애의 루틴 바

“오늘은 이 루틴으로 준비할게요”

메디큐브 사용 가이드에 따라 게스트가 직접 체험하고, 호스트가 대화를 이끕니다. 제품 선택의 이유와 실제 사용법을 짧은 자막으로 연결합니다.

PDRN 앰플 · AGE-R 부스터 프로 X2회차별 하나의 주력 제품에 집중토닝 또는 흡수·탄력·광채 중 해당 회차의 기능만 설명
장면 03 / 팬에게 남기는 루틴

“다음 손님은 누구일까요?”

셀럽의 루틴 카드·팬에게 보내는 한마디로 마무리하고 다음 게스트를 예고합니다. 팬 반응이 높은 순간과 사용법은 별도 쇼츠로 발행합니다.

공유하고 싶은 셀럽 루틴 카드메디큐브 세트·제품·고정 엔딩 반복저장·공유 가능한 제품 사용 순서와 회차별 원문 링크

팬덤을 움직이는 장치

사전 질문 모집 → 최애의 새로운 모습 공개 → 팬 메시지·다음 게스트 예고로 시청과 참여를 연결합니다. 출연자별 재생목록과 쇼츠로 반복 탐색을 만듭니다.

메디큐브를 기억하는 장치

고정 루틴 바, 회차별 고민 카드, 동일한 제품 사용 안내 형식으로 셀럽의 장면과 브랜드의 기능을 함께 기억하게 합니다.

성공을 확인하는 기준

재방문 시청자·공유·팬 질문 참여, 브랜드 회상·제품 기능 이해, 회차별 UTM 제품 방문을 분리해 측정합니다.

셀럽 섭외를 전제로 한 기획 제안. 실제 촬영은 제품별 사용 가이드와 위생 기준에 맞춰 진행합니다.
